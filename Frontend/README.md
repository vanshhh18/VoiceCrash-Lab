# VoiceCrashLab Frontend

React + TypeScript dashboard for VoiceCrashLab — a tool to connect any HTTP audio-in voice agent, generate adversarial audio test suites, test the agent, and evaluate responses.

## Tech stack

- React + TypeScript
- Vite
- Tailwind CSS v4
- Framer Motion
- Recharts

## Installation

```bash
npm install
```

## Development

```bash
npm run dev
```

Runs the app at http://localhost:5173.

## Build

```bash
npm run build
```

Type-checks (tsc) and produces a production bundle in `dist/`.
